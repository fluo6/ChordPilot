ChordPilot Help

Usage notes and a compact technical map of the analysis pipeline.

Version 0.1.0 • Built 2026-09-04 12:00 UTC

Basic Usage

  1. Choose an MP3 or WAV, then set up the tempo grid if the song needs manual alignment.
  2. Preview the grid with the metronome, set the analysis range if needed, then run Analyze.
  3. Use Song to adjust title, key, tempo, tuning, and playback speed.
  4. Edit bars from the Arrangement lane, Bar Detail, or the Table view.
  5. Use Arrangement Follow to keep the timeline on the playback cursor.
  6. Export the cleaned chart as TXT, CSV, JSON, or MusicXML.

Tempo Setup

  1. Start playback near the first useful musical section.
  2. Tap the downbeat key on beat 1 of each bar, and tap the beat key for the other beats.
  3. Use the generated grid to confirm BPM, downbeat, and bar alignment before analysis.
  4. Set an analysis start and end when intros, count-ins, silence, or outros should be skipped.
  5. Keep full-timeline mode when playback should preserve the original song timing, or chart only the selected range for a trimmed chart.

Hotkeys

Space
Play or pause the source audio.
D
Tap a downbeat, usually beat 1 of the bar, while Tempo Setup is active.
F
Tap the other beats in the bar while Tempo Setup is active.
[
Set analysis start at the current playhead position.
]
Set analysis end at the current playhead position.
\
Clear the current analysis range.
Backspace
Undo the most recent tempo tap or range action.
Esc
Leave Tempo Setup or cancel the current setup action.

Technical Notes

Shell Electron provides the desktop window, file dialogs, preload bridge, audio preview UI, and packaged Windows app.
Decode ffmpeg-static supplies FFmpeg for MP3/WAV conversion and preview rendering; scipy.io.wavfile reads generated WAV data.
Tempo + beats Fast mode uses a NumPy FFT onset envelope and autocorrelation tempo estimate; librosa.beat can add an optional beat-track estimate.
Pitch + key Bars use FFT-derived 12-bin chroma between configurable frequency limits; Essentia KeyExtractor is used for key when installed.
Chords Chord candidates are ranked by template coverage, essential tones, key fit, continuity, bass evidence, and complexity; pychord/music21 add library candidates when present.
Stems High Quality mode uses Demucs, usually htdemucs, via PyTorch or the demucs command; drums guide rhythm, other/accompaniment guides chords, bass guides slash/root evidence.
Lyrics Optional transcription uses faster-whisper first, then openai-whisper, with tiny/base/small model choices and full-mix or vocals-stem input.
Export + cache Sessions and analysis cache are JSON; MusicXML is rendered with Python ElementTree, while TXT/CSV/JSON use standard Python writers.
