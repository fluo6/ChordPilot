# Bass fretboard texture

`bass-rosewood.png` is a generated photorealistic rosewood texture created for ChordPilot with the built-in image-generation tool on 2026-10-15. It is not a photograph of a specific instrument. Strings, frets, inlays and note positions are drawn by the app so the same texture supports four- and five-string basses with accurate tuning and geometry. No external image or runtime download is required.
